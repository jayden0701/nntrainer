# nntrainer 위임 작업의 재작업 비용

2026-11-18에 nntrainer 전용 작업의 로컬 원장과 완료 경계의 누적 카운터를 대조했다. 아래 크레딧은 당시 조사에서 사용한 Standard 속도 단가로 계산한 추정치다. 개별 실행의 속도 등급, 구독 실차감액, 부모 검토 토큰은 확인할 수 없었다.

| 검증된 작업과 관측 구간 | 모델 / effort | 추가 토큰 | 추정 크레딧 | 포함 범위 |
| --- | --- | ---: | ---: | --- |
| 완료 세션 재개 시 원장의 완료 상태를 다시 여는 수정 | GPT-6.1 Sol / medium | 230,315 | 1.37 | 이전 완료부터 회귀 테스트를 추가하고 통과한 시점까지 |
| C2C 평가 정밀도 수정 후 마무리 | GPT-6.1 Sol / medium | 1,846,949 | 6.81 | 수정 보고부터 재실행·해시 검증·문서 완료까지. 수정 자체의 비용은 분리 불가 |
| native Ridge 채점기에 블록 채점 추가 | GPT-6.1 Terra / high | 3,788,645 | 6.46 | 직렬 버전의 검증 이후에 맡긴 기능 확장 |

원장 수정 구간은 uncached input 4,160, cached input 223,744, output 2,411이다. 기계 판독 원장의 완료된 시도 합계에 위 구간을 다시 더하면 중복된다. 부모가 수행한 줄바꿈 수정 두 건은 개별 토큰 미측정이다.

검증된 전용 시도 7건의 합계는 66,738,863토큰, 추정 220.45크레딧이었다. native 벤치 개발·평가와 Transformers 공개 벤치 재현 두 건이 추정 크레딧의 약 59.6%였다. 작업 범위가 서로 달랐고, 동일 입력·완료 기준에서 모델과 effort만 바꾼 쌍은 발견하지 못했다. 이 자료로 설정별 실청구액이나 절감률을 정할 수 없다.

후속 작업은 기존 검증 데이터와 실행기를 먼저 확인하고, 장시간 실험은 셸 프로세스가 체크포인트를 저장하게 한다. 모델/effort 비교 시 입력·수락 조건을 고정하고 재시도와 부모 검증까지 같은 과제에 귀속한다. 과거 관측을 라우팅 기본값으로 승격할 때는 동등한 과제의 성공률과 성공당 비용을 함께 사용한다.
